# M1 — Read both prices at the same block

> Part of the learning curriculum. See `../ROADMAP.md` for the overall map.
>
> **Working mode:** you write the code; the coach explains, flags gotchas, and reviews the
> diff at the checkpoint. The coach does not write product code.

**Goal:** talk to Ethereum, read two WETH/USDC prices *at the same block* (Aave oracle +
Uniswap QuoterV2), and compute the divergence in basis points. The two disciplines that
define this milestone: **same-block pinning** and **BigDecimal decimal-safety**.

**RPC source:** Alchemy free hosted node (Ethereum mainnet). The endpoint URL carries a
secret key — it lives in `.env` (gitignored) and is **never committed or logged**.

## Concepts (the DeFi foundation)

1. **Block** — the chain advances in blocks (~every 12s), each with a number. State has a
   value *at each block*; a price "at block N" is a frozen fact. Reason for same-block
   pinning.
2. **Smart contract** — a program deployed on-chain at an address. Aave
   `AaveOracle.getAssetPrice(address)` → USD price (8 decimals); Uniswap `QuoterV2
   .quoteExactInputSingle(...)` → simulated swap output. We only *call* them.
3. **`eth_call`** — simulate a contract call; result with no gas, no wallet, no state
   change. Takes: contract address, encoded call data, and a **block tag**.
4. **ABI encoding** — contracts speak bytes. Call = 4-byte selector
   (`keccak256(signature)[:4]`) + args padded to 32 bytes (address left-pads to 32). Decode
   the return by slicing hex into 32-byte words. Aave returns one `uint256`; QuoterV2
   returns four words (MVP needs only the first, `amountOut`). Most error-prone part.
5. **Decimals (never `double`)** — on-chain values are big integers with an implied decimal:
   WETH 18, USDC 6, Aave oracle 8. `BigInteger` for raw integers, `BigDecimal` + explicit
   scale for prices. `double`/`float` banned in the price/amount path.
6. **Same-block pinning** — fetch the block number **once**, pass that exact block as the
   tag to **both** `eth_call`s. Skip the cycle if the block hasn't changed.

## Step 2 — ABI encoding: first real contract call (`eth_call`)

Call Aave's oracle via `eth_call` and get a real WETH USD price. **Decision taken: Bouncy
Castle for keccak256 + hand-roll the ABI** (smallest dep, learn the raw mechanics).

**What `eth_call` sends:**
```json
{"jsonrpc":"2.0","method":"eth_call","params":[
  {"to":"<contract address>","data":"<encoded call>"},
  "<block tag>"],"id":1}
```
- `to` — Aave oracle `0x54586bE62E3c3580375aE3723C145253060Ca0C2`
- `data` — ABI-encoded call (below)
- block tag — `"latest"` for Step 2 (same-block pinning is Step 5)

**Building `data` for `getAssetPrice(address)` = selector + padded arg:**
- Selector = first 4 bytes of **keccak256** (NOT SHA-256) of the exact signature string
  `getAssetPrice(address)` (types only, no spaces) → `b3596f07`.
- Argument = asset address (WETH `0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2`), left-padded
  with zeros to 32 bytes.
- Concatenate: `0x b3596f07 000...000 c02aaa39...756cc2`.

**Decode:** result is one 32-byte word = `uint256` with **8 decimals**. Hex → `BigInteger`
→ scale by 1e8 → `BigDecimal` (e.g. `310000000000` = `$3100.00000000`).

**Tasks (you write):**
1. Add Bouncy Castle (`org.bouncycastle:bcprov-jdk18on:<1.78+>`); keccak via
   `org.bouncycastle.jcajce.provider.digest.Keccak.Digest256`.
2. `AbiCodec` as small testable pure functions: `selector(signature)` → byte[4];
   `padAddress(addr)` → 32-byte hex; `encodeGetAssetPrice(asset)`;
   `decodeUint256(resultHex)` → `BigInteger`.
3. Add `callContract(to, data, blockTag)` to the service (the `eth_call` envelope);
   `getAaveWethPrice()` = encode → call → decode → scale → `BigDecimal`.
4. Prove it: endpoint/log the WETH USD price; sanity-check against the real market price.

**Concepts:** keccak256 ≠ SHA-256 (standard `MessageDigest` gives the wrong selector);
hex ↔ bytes ↔ `BigInteger` at every boundary; scale with `BigDecimal` (`movePointLeft(8)`),
never `/ 1e8` on a double.

**Gotchas:** signature string is exact (types, no spaces; one wrong char = wrong selector);
keep hex even-length; `"latest"` tag only; lowercase/normalize addresses when padding
(mixed-case is checksum format).

**Checkpoint — bring to the coach:** `AbiCodec` + unit tests + `eth_call` wiring + the
printed WETH price. Reviewed: selector via **keccak** (test `getAssetPrice(address)` →
`b3596f07` first — fastest proof), padding correct, decode+scale with `BigDecimal` (zero
`double`/`float`), price realistic.
